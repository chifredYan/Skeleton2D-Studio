# Skeleton2D Studio

Web（HTTP 本地服务）版 Godot Skeleton2D 动画制作工具。内置 15 骨正面 T-pose 人形模板（头 1 + 上身/下身 + 上臂/下臂/手 ×2 + 大腿/小腿/脚 ×2）+ 武器模板，支持人形/武器挂接或分离、贴图绑定、逐帧动画设计，导出 Godot 4.x 直接可用的场景文件（零运行时代码）。上传贴图自动降采样至 ≤1024px，避免大图卡死。

**自动保存双保险**：编辑自动存 localStorage + 本机服务端磁盘（`.autosave/`）；内嵌预览等 localStorage 不持久化的环境，刷新后自动从服务端恢复工程与贴图。「重置工程」会同时清掉两处存档。

## 启动

```bash
cd skeleton2d-studio
npm run serve        # 或: node serve.mjs
# 浏览器打开 http://localhost:8788
```

零 npm 依赖，无需 install。Node 18+ 即可。

## 工作流

1. **上传贴图**：工具栏「上传贴图」导入 PNG（躯干/头/四肢/武器各部件）
2. **绑贴图**：左侧骨架树选中骨骼 → 右侧「绑定贴图到此骨」（图片自动缩放进该骨的色块框内）→ 调偏移/旋转/缩放/**透明度**/层级。每根骨骼有不同颜色的半透明色块包裹（工具栏「色块」开关），选中骨拖四个角点可调色块大小
   - **7 层贴图层级**：左栏底部「贴图层级」面板（底层特效/腿/下身/上身/手臂/头/顶层武器），**拖动贴图卡片到目标层**即可改显示顺序；层号越大越靠上，层内顺序由 z 微调（附件属性里也可改所在层）。层级直接决定视口显示与导出的 z_index（层×100+层内z）
   - 视口默认 400% 缩放打开（滚轮可 20%~1000% 调整）；每根骨骼的色块为全局均匀分布的 17 种互不相同颜色
3. **对接武器**：骨架树「对接 (Dock)」选中 dock → 右侧勾选/取消「挂接在一起」，可调对接偏移与旋转。**默认分离**——武器独立场景独立动画：对 Grip 骨做位置/旋转关键帧即可做御剑、飞剑、悬浮绕体等效果；需要手持武器时再勾选挂接
4. **做动画**：时间轴选帧 → 视口拖拽（灰点=移动位置，蓝条=改角度，Shift 反过来）→「K帧(全部)」；或「⧉上一帧」复制上一帧姿态再微调（逐帧工作流）；默认自动 K 帧 + 步进（无补间），可按轨道切换补间
5. **导出**：右侧「导出」区选模式 → 导出 ZIP → 解压到 Godot 工程任意目录，打开 .tscn 即用

## 导出产物

```
humanoid.tscn / weapon.tscn   # Skeleton2D + Bone2D + Sprite2D + AnimationPlayer
textures/*.png
meta.json                # dock 挂点信息（Marker2D 名称、偏移）
```

- **合并模式**：武器骨并入人形场景（Grip 成为 HandR 的子骨），单场景即完整角色
- **分离模式**：两个场景；人形手部带 `Dock_HandR` (Marker2D)，运行时一行挂接：

```gdscript
var weapon = preload("res://weapon.tscn").instantiate()
$Humanoid/LowerBody/UpperBody/UpperArmR/ForeArmR/HandR/Dock_HandR.add_child(weapon)
```

## 导出验证闭环

```bash
npm run validate
```

构建样例工程 → 导出两种模式 → 自动调用本机 Godot 4.7.2（`--headless --import` + 验证脚本）实际加载场景、播放全部动画。设置 `GODOT_PATH` 环境变量可指定 Godot 路径。

## 快捷键

| 键 | 功能 |
|---|---|
| 空格 | 播放/暂停 |
| ← / → | 上一帧 / 下一帧 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| 拖灰点（关节） | 移动骨骼位置 |
| 拖蓝条（骨骼） | 改骨骼角度（绕父关节） |
| 拖色块角点（选中骨的 4 个白点） | 调骨骼长/色块宽，**框内贴图强制跟着缩放** |
| Shift+拖拽 | 灰点/蓝条行为互换 |
| 右键拖拽 | 平移视图 |
| 滚轮 | 缩放 |
| Shift+点击关键帧 | 删除该关键帧 |

## 工程

- 自动保存到浏览器 localStorage；「导出工程文件 (.json)」可跨机器/备份
- 与技术方案的差异：动画直接内嵌 .tscn（而非独立 .tres，少一层文件）；存储用 localStorage（MVP 简化）；贴图未做图集（二期）
